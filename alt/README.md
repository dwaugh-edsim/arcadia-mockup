# Arcadia Entertainment — multi-page site (`alt/`)

Static, zero-build multi-page alternative to the single-page mockup at the
repository root. Home / Work (+ per-show pages) / About / Library & Rights /
Partnerships / Contact. Typography: Fraunces + Archivo.

**Maintainers (human or AI): read [`AGENTS.md`](AGENTS.md) first** — it
explains the structure, the rules, and the common edit recipes.

Preview locally: `python3 -m http.server 8000` from the repo root, then open
`http://localhost:8000/alt/`.
